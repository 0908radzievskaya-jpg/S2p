# Почасовой сбор исходных данных из почты

Скрипт читает несколько IMAP-ящиков, обрабатывает только новые письма, сохраняет локальные копии писем и материалов, извлекает текст из вложений и формирует ежедневный Excel-отчет по исходным данным для проектирования.

## Что делает

- подключается к нескольким IMAP-ящикам без изменения статуса писем;
- обрабатывает только новые письма по локальному `state`, а не по флагам на сервере;
- сохраняет `.eml`, текст письма, вложения и скачанные по ссылкам файлы;
- раскладывает материалы по папкам `archive/YYYY-MM-DD/ящик/отправитель/сообщение`;
- анализирует `pdf`, `docx`, `xlsx`, `html`, `txt`, а также страницы и файлы по ссылкам;
- если в письме есть ссылка на страницу, дополнительно обходит вложенные ссылки внутри этой страницы с ограничением по глубине и скачивает найденные материалы в отдельную подпапку ссылки;
- классифицирует материалы по проектным разделам;
- пополняет ежедневный отчет `reports/report-YYYY-MM-DD.xlsx`;
- оценивает достаточность исходных данных: `достаточно`, `частично достаточно`, `недостаточно`.

## Подготовка

1. Скопируйте `config.example.json` в `config.json`.
2. Заполните параметры IMAP-ящиков.
3. Убедитесь, что доступен Python 3.11+ и установлен `openpyxl`.

Опциональные библиотеки для более качественного разбора:

- `requests`
- `beautifulsoup4`
- `pypdf` или `PyPDF2`

Параметры загрузки ссылок:

- `link_follow_depth` — глубина обхода вложенных ссылок внутри страницы;
- `max_downloaded_files_per_link` — ограничение на число сохраненных файлов по одной исходной ссылке.

## Запуск

```powershell
python .\mail_automation.py --config .\config.json
```

Если один из IMAP-серверов отвечает нестабильно, скрипт ограничивает ожидание через `imap_timeout_seconds` в конфиге.

## Структура

- `mail_automation.py` — основной скрипт.
- `.state/processed_messages.json` — локальный state уже обработанных писем.
- `archive/` — сохраненные письма и материалы.
- `reports/` — ежедневные Excel-отчеты.

## Ограничения

- Для старого бинарного Excel `.xls` скрипт сохраняет файл, но не гарантирует текстовый разбор без дополнительных библиотек.
- Если модуль для чтения PDF не установлен, PDF будет сохранен, а в отчете появится пометка о недоступности извлечения текста.
